Cull is a modern Electron-based desktop application designed to help you regain control over your system's storage. It features a sleek interface, built-in safeguards, and powerful targeted scans to clean up cache, temp files, and leftovers across all your drives without ever touching critical system files.

---

## ✨ Features

- **🎨 Minimalist & Modern UI**: A completely custom, distraction-free interface.
- **🚀 Low Performance Mode**: Got an older PC? Toggle Low Performance mode to disable heavy animations and ensure Cull runs silky smooth.
- **🌈 Multiple Themes**: Customize your experience with beautiful themes including *Aurora Glass*, *Ocean*, *Midnight*, *Forest*, and *Sunset*.
- **🔍 System Bulk Scan**: Scan your **entire system** (C:\, D:\, E:\, etc.) at once with a single click.
- **🎯 Targeted Scans**: Specifically hunt down:
  - Game Data (Steam/Epic installs)
  - Leftover App Data (Large abandoned folders in AppData)
  - Suspicious/Unwanted Temp Files
- **🛡️ Built-in Safety**: System and Windows folders are strictly ignored. Cull *never* deletes your core applications.
- **🗑️ Smart Deletions**: Review everything before cleaning. Choose to move items safely to the Recycle Bin, or use the **Permanent Delete** button if you're sure.
- **📊 Real-time Progress**: Enjoy real-time loading bars and toast notifications so you always know exactly what Cull is processing.

## 🛠️ How to Use

### Installation

1. Go to the **Releases** tab on GitHub.
2. Download the latest `Cull Setup 1.0.0.exe` (Installer).
3. Run the application!

### Getting Started

1. **Dashboard Overview**: When you open Cull, you'll see your primary drives and their current capacity.
2. **Quick Scan**: Click the **Scan** button in the dashboard to do a quick pass over your common temp and cache folders.
3. **Bulk Scan**: Want a deep clean? Navigate to **Targeted Scans**, select **All Drives (Bulk Scan)**, and let Cull find reclaimable space across your entire PC.
4. **Review & Clean**: After a scan, Cull will present a list of files. Select the ones you want to remove, and click **Review & clean selected**.
5. **Recycle Bin**: Manage your Recycle Bin directly from the app to permanently free up that reclaimed space.
